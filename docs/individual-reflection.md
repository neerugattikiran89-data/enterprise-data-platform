# Individual Reflection

## My Contribution

I worked on developing an enterprise data platform for e-commerce data processing.

My responsibilities included:

- Preparing and loading Olist CSV datasets into PostgreSQL.
- Developing Airflow DAGs for automated CSV and REST API ingestion.
- Configuring Debezium and Kafka for change data capture.
- Setting up separate source and warehouse PostgreSQL databases.
- Developing dbt staging and incremental transformation models.
- Defining data quality tests using dbt schema tests.
- Integrating the different components using Docker Compose.

## What I Learned

Through this project, I gained practical experience with:

- Building batch data ingestion pipelines.
- Workflow orchestration using Apache Airflow.
- PostgreSQL database management.
- Change data capture using Debezium and Kafka.
- Data transformation using dbt.
- Containerizing services using Docker Compose.
- Understanding end-to-end data engineering architecture.

## Challenges

One of the main challenges was integrating multiple services and configuring communication between Docker containers. I also worked through database connection and data transfer issues while developing the pipeline.

## Conclusion

This project improved my understanding of real-world data engineering workflows and gave me practical exposure to building an integrated data platform.
